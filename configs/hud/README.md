# configs/hud

Layouts estáticos usados pelo pipeline de OCR do HUD.

Cada layout deve informar:

- resolução de referência;
- versão/schema;
- regiões normalizadas derivadas de fixture real;
- somente campos cuja posição é de fato estável.

Não colocar HP aqui quando a posição depender da ordenação dinâmica da lista de jogadores.
